# AI-Powered Customer Complaint Management System

An intelligent customer complaint handling application built with FastAPI, LangGraph, Groq LLM, React, Redux, and Vite.

## Architecture

- **Backend (`backend/`)**: FastAPI application with LangGraph agentic workflows, SQL database connection, models, schemas, and document parsers.
- **Frontend (`frontend/`)**: React + Vite application with Redux Toolkit state management and modular UI components (`LeftForm`, `RightCopilot`).
- **Sample Data (`sample_data/`)**: Test data files (PDFs, emails, etc.) for testing document parsing and copilot interactions.
